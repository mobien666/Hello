## 3. 文字数・空白・改行・句読点・記号の設計

### 3-1. 文字数の型（全角換算）

| 型 | 文字数 | 使いどころ | 比率 |
| --- | --- | --- | --- |
| ⚡ 一言 | 20〜50字 | 共感・日常。一瞬で読めて反応されやすい | 40% |
| 📝 主力 | 60〜110字 | 共感＋ひとこと・問いかけ | 50% |
| 📖 読み物 | 120〜140字（Premium なら超えてもよい） | 体験・価値観。フォローのきっかけになる | 10% |

- 💡 **140字を使い切らない**。余白がある方が「スッと読める」印象になり、女性のタイムラインで浮かない
- Premium で長文を書くときも、**タイムラインで「さらに表示」の前に見える部分だけで完結**させる（**推測です**：折りたたまれる位置は端末や表示によって変わるので、最初の3〜4行で伝わるように書く）

### 3-2. 改行と空白

- **1行目は15字以内が目安**（**推測です**：スマホの1行はおよそ全角16〜22字。端末と文字サイズで変わるので、1行目が途中で折り返されない長さにしておく）
- **1行は短く、意味のまとまりごとに改行**（読点「、」の代わりに改行を使う）
- **空行でブロックを分ける**：2〜4ブロックが読みやすい
- 最後の1行は**空行を挟んで独立**させる → 余韻が残り、読み返されやすい

```
[フック] ← 1行目。短く・問いかけか言い切り
[本文]   ← 2〜3行
（空行）
[余韻 or 問い] ← ここでリプを誘う
```

### 3-3. 句読点

| 使い方 | 印象 | 使いどころ |
| --- | --- | --- |
| 行末に「。」をつけない | やわらかい・話し言葉 | 基本はこれ |
| 行末に「。」をつける | 落ち着き・誠実・言い切り | 価値観や「ここは伝えたい」の1行だけ |
| 「、」を多く使う | 硬い・説明っぽい | 避けて、改行で代わりにする |
| 「…」 | 間・余韻 | 1投稿1回まで |
| 「！」 | 元気・営業っぽさ | ほぼ使わない（押しが強く見える） |
| 「？」 | 問いかけ | リプを誘う投稿の最後に使う |

### 3-4. 記号・絵文字

- 絵文字は **1投稿0〜1個**（多いと軽く見え、業者っぽくなる）
- ◎ おすすめ：☕ 🌙 🍵 📚 🌿 ☁️（暮らし・安らぎ）
- ✕ 避ける：♡ 💋 🔥 😘 🍑 など（恋愛や性を連想させ、色恋営業に見える）
- 「・」の箇条書き：価値観の投稿で使うと整って見える
- 「」：自分や相手のセリフを入れると共感されやすい
- **ハッシュタグは基本つけない**。業種のハッシュタグ（#女風 など）は営業っぽく見えるので使わない（**推測です**：センシティブな内容と判定されて表示が抑えられる可能性もある）
- **本文に外部リンクは貼らない**（**推測です**：外部リンクがあると表示が伸びにくいという検証報告が多い）

## 4. リプを増やす設計

1. **答えやすさが一番**：二択・一言で答えられる・正解がない問いにする
2. **自分の答えを先に書く**：答える側の心理的なハードルが下がる
3. **投稿して30〜60分はリプに張り付く**（**推測です**：最初の反応の速さがおすすめ表示に影響するとよく言われる。公式に数値は出ていない）
4. **リプには全部返す**。返事は「相手の言葉を拾う＋ひとこと肯定」
5. **返事で話を広げすぎない**：DM へ誘ったり会う話をしたりしない（営業・色恋に見える）
6. 他の人の投稿にも**やさしいリプを1日5〜10件**（女性ユーザー・セルフケア系アカウントなど）。ただし**女性のアカウントに自分から絡みにいくのは控えめに**。怖がらせない距離感を優先する

### リプへの返事の型

相手：「アイスです🍨」
返事：アイス仲間だ
      何味が好きですか？
```

```

## 6. NG → OK の書き換え例

| ❌ NG | 理由 | ⭕ OK の方向 |
| --- | --- | --- |
| 「本日20時〜空きあります！DMで✨」 | 営業・出勤の告知 | 投稿しない。日常の投稿に置き換える |
| 「君に会いたいな…」「僕だけ見てて」 | 色恋・依存をあおる | 誰に向けても成り立つ肯定の言葉にする（①〜④） |
| 「昨日のお客様が〜って言ってくれて」 | 守秘義務違反。本人が特定されるおそれ | 「よく聞く悩みなんだけど〜」と一般化する（それでも本人が読んで自分のことだと気づく内容は避ける） |
| 性的なことを連想させる言葉・絵文字・写真 | セラピストとしてふさわしくない。規約上のリスク | 一切使わない |
| 「〇〇店のセラピストより上手い」 | 他のセラピスト・他店への批判 | 比較しない。自分の価値観だけを話す |
| 「フォローしてくれた人だけに特別な〜」 | 囲い込み・営業っぽい | 誰にでも開かれた言葉にする |
| 「寂しい人、話聞くよ。DMして」 | DM への誘導。出会い目的に見える | リプで気軽に返せる問いかけにする（⑪〜⑭） |
| 愚痴・ネガティブな発言・病んでいる投稿 | 安心感が崩れる | 弱さを見せるなら「立ち直った後」の視点で書く（⑲） |

## 7. プロフィール・固定ポスト（投稿以外の土台）

- **名前**：呼びやすく、ひらがなかカタカナ2〜4文字
- **プロフ文**：「どんな人か」と「何を大事にしているか」を書く。料金・予約の案内は書かない
  ```
  話を最後まで聞くのが得意
  否定しない・急かさない・比べない
  疲れた日に読むと少し楽になる言葉を置いてます☕
  ```
- **アイコン**：清潔感があり、露出がないもの。顔を出すかどうかは所属店のルールと身バレのリスクで判断する
- **固定ポスト**：⑲のような「人柄が伝わる読み物」か、いいねが一番多かった共感ポスト

> プロフに所属店の情報を載せるかどうかは、店のルール・風営法の広告規制・X の規約を踏まえて**自分で判断**してください（この戦略書では扱いません）。
