# 毎日の投稿候補づくり（手順）

表計算：`sns/x_posts.xlsx`（シート：使い方／候補／型／分析元／削除ログ）

1. **分析元を50件集める**
   - ウェブ検索 `site:x.com ＋テーマ語` を8〜10回。テーマ例：疲れ／優しい人／自己肯定感／眠れない夜／泣いていい／ご褒美／完璧じゃなくていい／否定しない／季節の話題
   - 前日までの分析元と同じURLは使わない
   - `sns/daily/日付/sources.json` に保存 → `python3 sns/post_manager.py add-sources …`
2. **伸びる型を導き出す** → `types.json` → `add-types`
3. **候補を30件作る**（`sns/x-strategy.md` のNGに当たるものは作らない） → `candidates.json` → `add-candidates`
   - 既存の候補・採用済み・戦略書テンプレとの類似度が0.5以上のものは自動で削除され、削除ログに残る
   - 削除して30件を下回ったら、足りない分を作り直して再投入する
4. **5件を厳選して提示** → `present 日付 ID ID ID ID ID`
   - 提示できるのは、状態が「候補」か「提示中」のものだけ（採用済みはスクリプトが拒否する）
   - 型・長さ・時間帯（朝・昼・夜）がばらけるように選ぶ
5. **採用番号を受け取ったら** → `adopt 日付 番号…`（採用列に ✅）
6. コミットしてプッシュする（コンテナが消えても表を残すため）

必要なら：`pip install openpyxl`
